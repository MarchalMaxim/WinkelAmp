# Round 8: sliders that dim, not only boost (2026-11-01)

You said some sliders could only boost. Now each widget below has one slider that takes it down to almost nothing. Rorschach's
"how present" was the model: it dims the ink, calms the motion and answers fewer attacks. At the old default values every
widget draws exactly what it drew (compared frame by frame with the previous version), and your saved show values keep their meaning.

`sheet.png`: one tile per widget, Prelude at about 2:06. Left half the default, right half the slider at its quietest end. A
nearly black right half is often just this moment: down there only the piece's hardest notes get through, so some widgets
stay dark for long stretches (up to a minute or more on Fischinger). Try the middle of the slider too.

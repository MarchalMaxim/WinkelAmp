# Widget TODO

Nothing starts without the owner's go-ahead.

- **Show the signals a widget follows.** A graph beside a clip or knob in the studio of how each signal moves through the
  song (`loud`, `level`, `rate`, `pace`, `rel`, `hit`), so the owner sees what a widget is being connected to.
- **A setup window for a clip.** The side panel is at capacity. When a widget is added or a clip opened, a larger window

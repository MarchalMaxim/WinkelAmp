## How this was made (rerunnable)

`node docs/compositions/classical/holst-mars/gen-picks.mjs` writes `picks.json`. Add `--json` to also print a summary: each set's id, hears, notes, span and attacks per 30 s.

- The script is deterministic.
- It throws on a non-slug id, a duplicate id, an empty set, unsorted notes or a bad note.
- The audio features (librosa onsets, 0.1 s loudness, CQT held tones) come from a Python script embedded in it, run with the `wa` venv. `WA_PYTHON` overrides the path.
- The audio result is cached in the OS temp folder as `winkelamp-holst-mars-audio-<hash>.json`.
- Validation: all 47 sets in a throwaway show, one clip per set with `listen: picks:<id>`. `check-show` gives 0 errors.

`picks.json` is shaped like this, sorted by start:

`{ "<set id>": { "hears", "source", "rule", "from", "to", "notes": [[start, end, midi, velocity], ...] } }`

Copy a set into a show as `"picks": { "<id>": { "notes": [...] } }`.

# The ten nature widgets, as built

Built 2026-11-06 by one Opus-high planner, one Sonnet builder, one Opus reviewer and one Sonnet fixer per widget, from `SYNTHESIS.md`. Each widget is `lab/tools/<id>.js`; its plan, with an "After review" section listing what the fixer changed, is `plans/<id>.md`; its test is `tests/<id>.test.ts`. All ten are in the lab (`TOOL_IDS` in `lab/index.html`) and in the studio catalogue. Judge them on the 60 Hz video `Liebesleid - nature widgets showcase - 1080p.mp4` (show `shows/liebesleid-nature.json`), not in the live lab. Verdicts go in `lab/ratings.md` as usual.

Every widget passes its own tests, `tests/snap-envelope.test.ts` (byte-identical SNAP copies) and `npm run widgets-check` on the prelude passage with no thrown error and no near-black run.
